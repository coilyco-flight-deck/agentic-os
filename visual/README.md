# Visual

On-screen brand surfaces for the agentic workflow. The stuff a viewer actually sees during a hands-free voice + face-driven coding stream, as opposed to the agent doctrine in the repo root.

## Contents

- **[vtuber-pet/](vtuber-pet/)** - the VTuber pet. An A-10 Warthog "Hog girl" that ships as a third transparent OBS overlay layer over the screen capture and webcam. Cursor-adjacent. Includes the hot-reload preview harness used to iterate on it.
- **[tracky-mouse.md](tracky-mouse.md)** - pointer to the Tracky Mouse cursor / HUD repo and the active branch. The cursor the pet sits next to and has to cohere with.

## Where the design reasoning lives

The deep design notes (palette, style triangle, silhouette spec, fleet metaphor) live in Kai's private vault, tagged `visual-identity`, not here. This folder carries the shippable assets and the iteration tooling. The work is tracked in the canonical tracker, not in this README.

## The shared visual language

All of these surfaces are one inked, two-tone hand. Teal `#45cdd0` is the live-signal layer (anything that animates or signals state), lavender `#b8a4d8` is the static chassis, near-black `#0d0a14` is the ground. The cursor reticle and the pet's cannon are deliberately the same teal targeting system so the fluffy reticle and the hard gun-girl read as one design, not two mascots.
