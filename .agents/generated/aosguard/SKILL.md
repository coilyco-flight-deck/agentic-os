# aosguard guarded CLI

Start with `aosguard --help`, then follow group help to the needed leaf.
Use a group's `describe` command when it is available for the pulled policy view.
The running CLI's help and describe output are authoritative for behavior and flags.

`references/commands.yaml` indexes every reachable leaf for lazy discovery.
