# The skillsmp workflow

Six steps. Do not skip ahead. Everything before "install" is cheap; install is the step that actually touches the user's filesystem with untrusted code, so it needs explicit consent.

- [Steps 1-2: auth and search](workflow-search.md) - `coily skillsmp` auth, keyword/AI search, client-side filters.
- [Step 3: automated vetting](workflow-vetting.md) - clone, threat model, the byte-level read checklist.
- [Steps 4-6: confirm, install, use](workflow-install.md) - show the URL, install on approval, apply the new skill.
