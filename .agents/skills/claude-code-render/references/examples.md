# Claude Code Desktop Render Examples

Six numbered probe blocks built on the techniques documented in [the SKILL body](../SKILL.md). The first five render as described; the sixth is a confirmed negative result kept for honesty. Visually confirmed in the Claude Code Desktop client on 2026-05-13.

Reproducing these requires the Claude Code Desktop client with the syntax highlighter active. Other clients (Chrome web, Android, terminal) may render differently. Paste the fenced block as-is into a chat message or notes surface that runs the same renderer. Full reproduction steps live in [example-markdown-negative.md](example-markdown-negative.md#how-to-reproduce).

## The six probes

- [I. sunrise()](example-sunrise.md) - four-color JavaScript landscape in one fence.
- [II. Phases](example-phases.md) - density-only crescent moon, no color.
- [III. Strawberry](example-strawberry.md) - two-color diff with in-color density seeds.
- [IV. forest()](example-forest.md) - Python structural scaffolding, purple class names.
- [V. heartbeat](example-heartbeat.md) - sparkline-glyph EKG pulse, density-only.
- [VI. markdown-headings-inside-fence](example-markdown-negative.md) - confirmed negative result plus reproduction steps.
