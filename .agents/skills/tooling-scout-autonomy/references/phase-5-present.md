# Phase 5 - Present and hand off

Flatten the top 3 contracts to chat for the operator to choose. This phase is a gate, not
an auto-build - projection is speculative and the operator picks which one earns a night.

For each of the top 3, present inline:

- Name, kind, and final leverage score.
- One-line goal and the done-condition.
- What it builds on (the composition), so the leverage is legible.
- Build effort in long-run units, and the headline risk.

**Approval is explicit-deny.** Present all three, let the operator pick one (or none, or
redirect). Do not start building before the pick - the whole point of the gate is that a
human chooses where the autonomous night goes.

Once picked, the chosen contract becomes the seed of a long-run session: hand it to the
operator's long-run execution skill verbatim as the run's contract. The other two
contracts stay in the notes file as the next candidates - a future run can pick up the
runner-up without re-scouting.

If the operator wants the run kicked off in the same session, proceed into the long-run
discipline with the chosen contract. If they want to run it elsewhere (a separate
overnight session, a dispatched headless job), hand back the contract as a copy-paste
block and stop here.
