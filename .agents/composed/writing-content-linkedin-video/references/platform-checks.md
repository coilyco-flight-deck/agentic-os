# LinkedIn platform checks

Use current first-party sources before producing a publish-ready export:

* [Video sharing troubleshooting](https://www.linkedin.com/help/linkedin/answer/a548372/)
  for file, duration, resolution, aspect ratio, frame rate, bitrate, and video
  safe-zone requirements.
* [Auto captions for videos](https://www.linkedin.com/help/linkedin/answer/a1327025)
  for caption availability and review behavior.
* [LinkedIn sharing guide](https://content.linkedin.com/content/dam/help/linkedin/en-us/LinkedIn-Sharing-Guide.pdf)
  for creative guidance.

## Verify

1. Record the check date and direct source links.
2. Distinguish upload requirements from creative recommendations.
3. Confirm the intended posting surface. Member posts, Pages, ads, articles,
   events, and LinkedIn Learning can have different limits.
4. Probe the final video and compare its actual container, codecs, duration,
   dimensions, aspect ratio, frame rate, bitrate, and file size with the current
   requirements.
5. Keep key text, faces, logos, and demonstrations inside the current safe zone.
6. Enable caption review during upload when available. Review names, technical
   terms, timing, and punctuation before captions become visible.

If first-party sources disagree, prefer the requirement for the exact posting
surface and report the discrepancy rather than silently choosing one.
