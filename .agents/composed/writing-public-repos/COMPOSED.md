# Writing in public coilysiren/ repos

Public repos: `eco-cycle-prep`, `eco-mods-public`, `website`, plus others listed in each repo's sibling table.

**Do not cite internal filenames or line numbers from `StrangeLoopGames/Eco`** - reads as a leak, unwelcoming to outside contributors.

Same caution for private siblings (`eco-mods`, `eco-configs`, `eco-mods-assets`, `eco-mods-assets-embeded`) when public output would expose their paths.

File *shape* is fine when already documented publicly (e.g. `WorldGenerator.eco` JSON schema at docs.play.eco).

Keep the knowledge (biome tables, schemas, observed behaviors), frame from public sources:

- Modding wiki: <https://wiki.play.eco/en/Modding>
- Auto-generated docs: <https://docs.play.eco/>
- Public EcoModKit repo
- User configs
- Observed server behavior
