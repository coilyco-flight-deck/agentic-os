# Issue-corpus note

The git-rendered Forgejo issue corpus is retired. The shared issue mirror and
lookup surface is now `forgejo-issues`.

This note remains only as a breadcrumb for the old design and should not be
revived as an active renderer or scheduled workflow.

For live issue lookup, use `aosguard ops forgejo issue view`. The `forgejo-issues`
service carries the replacement direction, tracked where that service is deployed.
